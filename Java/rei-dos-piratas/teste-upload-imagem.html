Teste de upload para o S3

Informe a key e a URL pré-assinada retornadas pela API e selecione a imagem. O navegador envia o arquivo diretamente ao S3.

A key deve corresponder ao objeto para o qual a URL foi assinada.

Preencha os campos para iniciar o teste.

Se o navegador bloquear a requisição: verifique se o CORS do bucket permite a origem desta página, o método PUT e o cabeçalho Content-Type. Para testar sem servidor local, abra este arquivo no navegador; dependendo da configuração do bucket, pode ser necessário servir a página por HTTP local para que a origem seja permitida.
